# 🍁 RangeAndFuel.ca (Fuelandrange)

> **Official Canadian Vehicle Fuel Economy, Electric Range & Cold Winter Degradation Intelligence Platform**

Comprehensive programmatic automotive platform built with Astro 4.10, React 18, Tailwind CSS, TypeScript, and Natural Resources Canada (NRCan) official EnerGuide testing datasets.

---

## 🚀 Key Features

* **🇨🇦 839 Programmatic SEO Pages:** 29 Makes, 80+ Models, 10 Canadian Provinces, and 11 Vehicle Classes.
* **❄️ -15°C Sub-Zero Winter Model:** Real-world Canadian thermodynamic cold range loss and fuel penalty calculation.
* **⛽ 10 Provincial Tariffs:** Real-time pump prices (¢/L) and electricity hydro rates (¢/kWh) by province.
* **⚠️ Transport Canada Recalls:** Official safety defect bulletins with CMVSS numbers and corrective dealer remedies.
* **⚡ Ultra Fast Performance:** 100% Static Site Generation (SSG), compiles 839 pages in ~6 seconds.
* **🔍 Schema.org JSON-LD:** Structured data for `Car`, `FAQPage`, `ItemList`, `CollectionPage`, `Organization`, and `Dataset`.
* **🛡️ Canadian Legal Suite:** PIPEDA, CASL, Quebec Law 25, Ontario Terms of Service, and testing disclaimers.

---

## 🛠️ Tech Stack

* **Framework:** [Astro 4.10](https://astro.build/)
* **UI Components:** React 18 & TypeScript
* **Styling:** Tailwind CSS (Cyber Slate Automotive Theme)
* **Search Engine:** Fuse.js client-side instant fuzzy search
* **Visuals:** Three.js 3D automotive HUD elements

---

## 🧞 Available Scripts

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build 839 static production pages
npm run build

# Preview production build locally
npm run preview
```
